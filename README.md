# 人生指南 × 拆书框架 × 科学核验 三源对照集

把 GitHub 上高星的《[高性价比人生指南](https://github.com/eternity4719/HowToLiveBetter)》（HowToLiveBetter，667 条建议、34 节、A/B/C 证据分级）与一个 166 本书的私人拆书笔记库（约 1300 个思维框架）、以及一批已用科学论文逐条核验过的调研报告做**逐条对照**：哪里观点一致，哪里有边界条件，哪里冲突，哪里互补。

> 状态：🚧 样章阶段（先做第 03/04/05/06 节，验收后铺开全量 34 节）

## 三源模型

| 来源 | 角色 | 证据强度 |
| --- | --- | --- |
| [HowToLiveBetter](https://github.com/eternity4719/HowToLiveBetter) | 对照基准：667 条建议，自带证据分级（A=荟萃分析/RCT/大型队列 435 条，B=177，C=55） | 引用原始文献 1675 条 |
| 拆书笔记库（166 本） | 观点方：每本拆出思维框架与反常识点 | 二手提炼（观点） |
| 深度调研报告（45 份重叠主题） | **裁决层**：对具体命题的论文级核验（作者+年份+样本量+效应量，部分含 DOI） | 一手核验（证据） |

## 判定口径（四档）

- **✅ 一致**：两侧主张同向，框架可直接互证
- **🟡 部分一致**：同向但有边界条件、适用人群或强度差异
- **❌ 冲突**：两侧主张相反或数据矛盾
- **🔀 互补**：不同问题域，但拼起来完整（如"防下行 vs 博上行"）

**裁决规则**：凡对照点在调研报告里有已裁决结论的，记录必须挂「调研佐证」并按证据定档——例如指南把"意志力会用完"（ego depletion）列入反面清单，而《认知觉醒》依赖该说法，调研佐证引用 Hagger 2016 多实验室复制（N=2141，d=0.04）后，该条按"❌ 冲突但指南正确"处理。

每条记录的形态：

```markdown
### ✅ 4.3 只看未来投入和回报 ↔ 《错误的行为》沉没成本
- 指南条目：第 4 节第 3 条（证据等级 B）｜[原文](https://github.com/eternity4719/HowToLiveBetter/blob/main/book/04-不要浪费时间.md)
- 对应框架：《错误的行为》沉没成本效应；《思考，快与慢》前景理论
- 调研佐证：（有则引用报告+论文，无则省略）
- 一致点：……；差异边界：……
```

## 方法与边界

- 对照粒度：以指南条目为单位（节号+条号），逐条在拆书库中找对应框架；医疗/法律细节类条目书库无对应的，在节文档里一句话归并说明，不逐条立记录。
- 预期记录量 200-300 条；引用指南条目只取「标题 + 说人话一句 + 原文链接」，不复整条粘贴。
- 本项目是独立第三方对照笔记，与 HowToLiveBetter 原作者无关联；对指南内容的引用均为署名转载/摘编。
